# MirageSSD 0.1.20 preview

This preview adds smaller verified reads from existing encrypted Mirage
payloads and a native, read-only Sophon source for publisher game assets.

## Encrypted cloud reads

After a complete frame has passed its existing authentication and plaintext
hash checks, Mirage retains a compact verification catalog independently of
the frame's data. A later sparse miss can fetch and verify a 64 KiB sector
instead of downloading the whole 4 MiB frame again. The integrated fixture
transferred 4,194,372 bytes on bootstrap and 65,536 bytes on a later eligible
miss. Bootstrap remains necessary, and catalogs currently live in memory.

Concurrent reads share immutable buffers and overlapping fetches. Eight
active miss owners bound demand work, with at most two background restaging
owners. Sparse reads avoid whole-payload restaging; dense reads retain bounded
lookahead. Restaging reserves the known payload size before downloading and
releases that reservation on failure.

Default frame, sector and proof residency budgets total 48 MiB, down from the
previous 128 MiB frame-cache ceiling. These are cache allocation limits, not
process memory measurements or local disk limits. Published encrypted formats
and stored data remain compatible.

## Native publisher asset source

The Windows filesystem host now supports `--sophon` with pinned local
manifests, selected export prefixes, and explicit memory and disk budgets.
Requested chunks are fetched directly over HTTPS, decompressed within bounds,
and checked against the manifest's length and MD5 before serving them.

Existing cache trees can be reused as read-only seeds. Verified seed chunks
are served without making duplicate owned disk-cache copies. Local and network
work have separate bounded admission, and simultaneous requests for the same
chunk share one fetch. The startup helper is `scripts/start-sophon-mount.ps1`.

Genshin asset probes covered seven complete files, direct CDN retrieval, and
disk-cache reuse after remount. Mounted tests cover listing, exact reads and
write refusal. Gameplay, launcher update/repair, and frame-time improvements
have not been qualified. This source is configured manually; the installer
does not automatically migrate a game or register it in the desktop UI.
Sophon manifest checks are separate from encrypted Mirage sector verification.

## Research and installation

The locked HTTP/2 dependency is updated to h2 0.4.16 to address
[RUSTSEC-2026-0258](https://rustsec.org/advisories/RUSTSEC-2026-0258).
The lockfile also includes quinn-proto 0.11.18, fixing the three QUIC advisories
reported by the full dependency audit.

The repository includes reproducible cache, transfer scheduling, compression,
and finer-grained verified-seek experiments. Prototype results are identified
separately from production behavior; no universal speedup is claimed.

Use the Windows setup executable for the bundled WinFsp prerequisite, or the
MSI when WinFsp is already installed. This remains an unsigned preview. The
macOS package uses the existing provider architecture and does not include
these Windows native filesystem improvements.
